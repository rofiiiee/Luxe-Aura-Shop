#  Luxe Aura | Premium Jewelry E-commerce Store

**Luxe Aura** is a sophisticated e-commerce platform designed for the high-end jewelry market. This project focuses on delivering a luxury user experience (UX) through a modern, responsive interface (UI) and robust front-end functionality.

---

##  Key Technical Features

* **Dynamic Product Management:** Integrated with an external **API** using the `Fetch API` to dynamically populate the store with the latest collections.
* **Persistent Shopping System:** Developed a smart **Aside Drawer Cart** that utilizes `LocalStorage`, ensuring customer selections are preserved even after closing the browser or refreshing the page.
* **Complete Authentication Flow:** Includes dedicated, styled pages for **Login** and **Signup**, providing a realistic e-commerce user journey.
* **Fully Responsive Architecture:** Crafted with a mobile-first approach, ensuring a seamless luxury experience across Desktops, Tablets, and Smartphones.
* **Premium Visual Identity:** Features a high-end aesthetic using **Glassmorphism**, smooth transitions, and elegant typography (Playfair Display & Montserrat).

---

##  Tech Stack & Tools

| Technology | Purpose |
| :--------- | :------ |
| **HTML5** | Semantic structure and SEO optimization. |
| **CSS3** | Modern styling, Flexbox/Grid layouts, and custom animations. |
| **JavaScript (ES6+)** | Core logic, DOM manipulation, and state management. |
| **Fetch API** | Handling asynchronous data requests for dynamic content. |
| **LocalStorage** | Client-side data persistence for the shopping cart. |
| **FontAwesome** | Professional vector icons for UI elements. |
